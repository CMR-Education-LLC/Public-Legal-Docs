# Spanish Montessori App - Public Legal Docs

Public legal documents for GitHub Pages (Privacy Policy, Terms of Service, COPPA direct notice).

## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` → folder **`/docs`**
4. Save

## Public URLs (after Pages is on)

Base: `https://cmr-education-llc.github.io/Public-Legal-Docs/`

- Privacy Policy: `.../legal/privacy-policy.html`
- Terms of Service: `.../legal/terms-of-service.html`
- COPPA Direct Notice: `.../legal/coppa-direct-notice.html`

Use these URLs in App Store Connect, Google Play, and the app.
